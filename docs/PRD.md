## 产品概述

**PingChang（平常）** 是一款微信小程序情绪慢社交应用，核心形式为「数字书信」。用户通过写长文字信件与陌生人建立深度情感连接，同时借助情绪月历记录个人成长轨迹。

**核心价值主张**：在快速刷屏的时代，提供一个慢下来、认真书写与感受的空间。

**目标用户**：20–28 岁，有写日记或阅读习惯，寻求真诚人际连接的年轻人。

## 首页

### 功能描述

首页是用户每日进入的核心落地页，聚合今日心情记录、去年的今天记忆、灵魂推荐和最近来信四个区域。

### 页面元素

| 区域 | 元素 | 说明 |
|------|------|------|
| 顶部 Header | 应用名「平常」 + 今日日期 | 深棕底色，白色文字 |
| 今日心情卡片 | 情绪选择 + 强度滑块 + 日记输入 + 记录按钮 | 未记录时展示完整组件；已记录时收起显示「今日心情已记录」 |
| 去年的今天 | 去年同日的情绪记录或信件摘要 | 仅当去年有记录时展示；点击跳转详情 |
| 灵魂推荐 | 横向滚动卡片，展示前2位推荐 | 显示匹配度、昵称、共同标签；「全部」链接跳转匹配页 |
| 最近来信 | 前2封收件，信封卡片样式 | 显示寄信人、标题摘要、时间；「信箱」链接跳转收件箱 |

### 交互说明

- 进入首页：同时请求 `getUser`、`getMemoryToday`、`getDailyRecommend`、`getInbox(0)`（取前2条）
- 每次 `onShow`：刷新收件箱前2条（处理新来信场景）
- 情绪记录成功：`moodDone = true`，心情卡片收起，toast 提示「情绪已记录」
- 点击推荐卡片：跳转对方主页 `/pages/match/profile/index?targetUid=xxx`
- 点击信件：跳转信件详情 `/pages/letters/detail/index?letterId=xxx`

### 业务规则

- 今日情绪每天只能记录一次（覆盖更新，不累加）
- 灵魂推荐横向区域最多展示2位（完整列表在匹配页）
- 「去年的今天」优先展示情绪记录，无情绪记录时展示信件

## 书信模块

### 写信页 (`pages/letters/write/index`)

#### 功能描述

用户选择收信人后，在信纸样式的编辑区撰写信件，达到字数门槛后方可发送。

#### 页面元素

| 元素 | 说明 |
|------|------|
| 收信人栏 | 显示「致：对方昵称」；通过路由参数传入 targetUid |
| 标题输入框 | 选填，最多 30 字 |
| 正文 Textarea | 信纸样式，左侧红线边距，横线背景 |
| 字数计数器 | 实时显示「当前字数 / 门槛字数」，进度条 |
| 蜡封印章 | 装饰组件，字数达标时变为激活态 |
| 封存寄出按钮 | 字数不足时禁用（opacity 0.4），达标后激活 |

#### 交互说明

- 字数实时计算：每次 `input` 事件调用 `validator.countWords()`，更新计数和按钮状态
- 点击发送流程：`moderateContent` → 内容安全通过后 → `sendLetter` → toast「信件已寄出」→ 返回上页
- 内容违规：toast 提示「内容包含违规信息，请修改后重新发送」，不关闭页面
- 页面可通过路由参数接收 `targetUid`、`targetNickname`、`isFirst`（是否首封信）

#### 业务规则

- **首封信（陌生人）**：正文字数 ≥ 150 字（`isFirst=true`）
- **回信（已建立通信）**：正文字数 ≥ 100 字（`isFirst=false`）
- 字数计算：去除首尾空格，中文字 + 英文单词数，不计标点和空格
- 所有 UGC 写入前必须调用 `moderateContent` 云函数，通过后方可写入数据库
- 后端 `sendLetter` 云函数独立重新计算 `word_count`，不信任前端传入值

### 收件箱 (`pages/letters/inbox/index`)

#### 功能描述

展示当前用户收到的所有信件列表，按时间倒序排列，支持分页加载。

#### 页面元素

| 元素 | 说明 |
|------|------|
| Tab 栏 | 「收件箱」/「已发出」两个 Tab，当前页高亮 |
| 信封卡片列表 | `envelope-card` 组件，显示寄信人头像首字、昵称、时间、摘要、字数 |
| 未读红点 | status=sent 时右上角显示红点 |
| 空状态 | 插画 + 「还没有来信，去发现灵魂匹配吧」+ 跳转按钮 |
| 悬浮写信按钮 | 右下角 FAB，点击跳转写信页 |

#### 交互说明

- 分页加载：每页10条，上拉触底加载下一页（`onReachBottom`）
- 下拉刷新：重置到第0页重新加载（`onPullDownRefresh`）
- 点击信封：跳转信件详情页

#### 边界状态

- 空列表：展示引导插画和跳转推荐按钮
- 加载中：3条骨架屏占位（Sprint 6 实现）
- 网络失败：toast「网络异常，请稍后重试」

### 信件详情 (`pages/letters/detail/index`)

#### 功能描述

信件详情页包含拆信动画和完整信件内容，是产品最核心的情感体验页面。

#### 页面元素

| 元素 | 说明 |
|------|------|
| 拆信动画 | `open-animation` 组件，status=sent 时自动触发 |
| 寄信人栏 | 头像首字 + 昵称 + 发信时间 + 「›」跳转对方主页 |
| 信纸区域 | `letter-paper` 组件，信件标题 + 正文 + 日期签名 |
| 回信按钮 | 固定在底部，点击跳转写信页（isFirst=false） |

#### 拆信动画 5 阶段规格

| 阶段 | 延迟 | 时长 | 属性变化 | 缓动 |
|------|------|------|----------|------|
| 1. 蜡封消失 | 0ms | 280ms | opacity + scale → 0 | ease-out |
| 2. 封口翻折 | 100ms | 550ms | rotateX → 180deg | ease-in-out |
| 3. 信纸滑出 | 300ms | 500ms | scaleY → 1 | cubic-bezier(0.34,1.1,0.64,1) |
| 4. 文字淡入 | 500ms | 300ms | opacity → 1 | ease |
| 5. 签名淡入 | 650ms | 300ms | opacity → 1 | ease |

#### 交互说明

- 页面加载：调用 `getLetter`，自动将 `status` 从 `sent` 改为 `read`
- 动画触发：仅当 `status === 'sent'` 时触发拆信动画；已读信件直接展示内容
- 防重入：`isAnimating` flag 防止重复触发动画
- 动画结束后：`open-animation` 组件触发 `animDone` 事件，父页面显示信件内容

#### 业务规则

- 只有 `from_uid` 或 `to_uid` 等于当前用户的信件可查看（后端校验）
- 拆信动画完整播放率目标 ≥ 95%（Sprint 8 内测指标）

## 情绪旅程

### 情绪旅程页 (`pages/journey/index/index`)

#### 功能描述

用户查看自己的情绪历史，包括月历热力图和30天趋势折线图。

#### 页面元素

| 元素 | 说明 |
|------|------|
| 月份选择器 | 「‹ 2026年5月 ›」，不允许选择未来月份 |
| 情绪月历 | `emotion-calendar` 组件，7×N 格，有记录的日期显示情绪颜色圆点 |
| 日期详情 | 点击有记录的日期展示：情绪类型徽章 + 强度点 + 日记内容 |
| 趋势折线图 | `trend-chart` 组件（wx-charts），过去30天情绪强度曲线 |
| 空状态 | 本月无记录时展示引导文案 |

#### 情绪颜色映射

| 情绪 | 颜色 | CSS 变量 |
|------|------|----------|
| 开心（happy） | #C4622D（铁锈红） | `--m-happy` |
| 平静（calm） | #2E6E65（青绿） | `--m-calm` |
| 难过（sad） | #5A3D7A（紫） | `--m-sad` |
| 焦虑（anxious） | #8C5E00（琥珀） | `--m-anxious` |
| 复杂（mixed） | #7A5C3E（暖褐） | `--m-mixed` |

#### 交互说明

- 进入页面：同时调用 `getMoods(year, month)` 和 `getMoodTrend()`
- 切换月份：调用新月份的 `getMoods`，月历重新渲染
- 点击有记录的日期：在日历下方展示该日情绪详情（无需跳转新页）
- 点击无记录的日期：展示「X月X日 没有情绪记录」

#### 业务规则

- 同一天只有一条情绪记录（覆盖更新，`saveMood` 实现 upsert）
- 月历渲染性能目标 < 200ms
- 折线图无数据日期显示为断点（不连线），wx-charts 配置 `format: val === 0 ? null : val`

## 灵魂匹配

### 灵魂匹配页 (`pages/match/index/index`)

#### 功能描述

展示每日推荐的灵魂匹配列表，用户可选择写信或跳过。

#### 页面元素

| 元素 | 说明 |
|------|------|
| 页面标题 | 「今日灵魂推荐」+ 副标题「每日更新，真诚相遇」 |
| 推荐卡片列表 | `soul-card` 组件：头像首字、昵称、匹配度%、共同标签、介绍摘要 |
| 操作按钮 | 每张卡片下方：「跳过」（ghost）+ 「写信给TA」（primary） |
| 空状态 | 「今天的推荐已看完，明天再来看看」 |

#### 业务规则

- **免费用户**：每日最多 3 位推荐（`getDailyRecommend` 返回 limit=3）
- **会员用户**：每日最多 5 位推荐（`getDailyRecommend` 返回 limit=5）
- 推荐每日 0 点更新（`getMatches` 定时触发）
- 跳过某用户（`skipUser`）后，当日推荐列表立即移除该用户
- 已有通信关系的用户不出现在推荐列表
- 冷启动兜底：可推荐用户 < 3 人时，插入官方「平常信使」账号补全到 3 人

#### 匹配算法（Jaccard 相似度）

```
基础分 = |A ∩ B| / |A ∪ B| × 100
加权修正：
  + 10  活跃时段相同
  + 5   书信频率相同
  + 8   对方7天内活跃
  = -1  已有通信关系（不推荐）
  = -1  今日已跳过（不推荐）
最终分数上限：100
```

## 用户系统

### 注册引导 (`pages/onboarding/index/index`)

#### 功能描述

新用户完成「精神身份证」填写的3步引导流程，建立账号后进入首页。

#### 步骤设计

**Step 1：基本信息**
- 昵称（必填，≤ 20字）
- 一句话介绍（必填，20–60字）

**Step 2：兴趣标签**
- 从 30 个预设标签中选择 3–5 个
- 少于3个不可进入下一步，超过5个弹出提示阻止继续选择

**Step 3：书写偏好**
- 活跃时段：清晨 / 午后 / 夜深
- 书信频率：每周一封 / 两周一封 / 随缘

#### 预设标签（30个）

文学、诗歌、哲学、历史、音乐、电影、摄影、绘画、旅行、美食、自然、心理、科幻、悬疑、动漫、游戏、运动、瑜伽、冥想、园艺、手工、烹饪、茶道、书法、天文、生物、经济、社会学、建筑、时尚

#### 交互说明

- 进度条实时更新（当前步骤/总步骤）
- Step 1 → Step 2：前端校验昵称非空 + 介绍字数合规
- Step 2 → Step 3：前端校验标签已选 ≥ 3 个
- Step 3 完成：调用 `createUser` 云函数，成功后跳转首页
- 注册前对介绍内容做 `moderateContent` 安全检查

#### 业务规则

- 每位微信用户只能注册一次（后端检查 `OPENID` 是否已存在）
- 一句话介绍字数由后端重新校验（不信任前端）
- 注册成功后触发首次匹配计算（TODO）

## 全局业务规则

### 字数规则

| 场景 | 最低字数 | 最高字数 | 强制程度 |
|------|----------|----------|----------|
| 陌生人首封信 | **150 字** | 无限制 | 前端+后端双重校验 |
| 已建立通信的回信 | **100 字** | 无限制 | 前端+后端双重校验 |
| 心情日记 | **30 字**（可选填）| 无限制 | 后端校验（可不填） |
| 一句话介绍 | **20 字** | **60 字** | 前端+后端双重校验 |
| 对方主页书写摘要展示 | — | **50 字**（截断） | 后端截取 |

### 每日推荐配额

| 用户类型 | 每日推荐数量 |
|----------|-------------|
| 免费用户 | 3 位 |
| 会员用户 | 5 位 |

### 内容安全

- 所有 UGC（信件正文、心情日记、个人介绍）写入前必须调用 `moderateContent`
- 使用微信内容安全 API v2（`cloud.openapi.security.msgSecCheck`）
- `suggest = risky` 时拒绝写入并提示用户；`review` 时放行并记录（人工审核）
- 安全 API 异常时记录日志、放行（避免影响正常用户）

### 错误码

| 错误码 | 含义 | 前端处理 |
|--------|------|----------|
| 1001 | 内容未通过安全检测 | 提示修改，不关闭编辑页 |
| 1002 | 字数不足 | 提示当前字数和门槛，不关闭编辑页 |
| 1003 | 对方已拒绝接收 | 提示并返回上页 |
| 1004 | 每日推荐已用完 | 展示空状态页面 |
| 1005 | 活跃书信组数已达上限 | 提示并引导归档 |
| 9001 | 数据库操作失败 | toast「网络异常，请稍后重试」 |
| 9002 | 云函数超时 | 自动重试1次，仍失败则提示 |

## 边界状态设计

| 页面 | 边界状态 | 设计方案 |
|------|----------|----------|
| 收件箱 | 空列表 | 插画 + 「还没有来信，去发现灵魂匹配吧」+ 跳转按钮 |
| 已发出 | 空列表 | 插画 + 「还没有发出过信件」+ 「写一封信」按钮 |
| 灵魂匹配 | 推荐用完 | 插画 + 「今天的推荐已看完，明天再来看看」|
| 情绪旅程 | 本月无记录 | 插画 + 「记录今天的心情，开始你的情绪旅程」|
| 情绪旅程 | 折线图断点 | 无数据的日期不连线，wx-charts 格式化函数返回 null |
| 首页 | 未记录今日情绪 | 展示情绪记录组件（完整 mood-widget）|
| 首页 | 已记录今日情绪 | 情绪卡片收起，显示「今日心情已记录 ✓」|
| 首页 | 无去年记录 | 不展示「去年的今天」区域 |
| 写信页 | 字数不足 | 发送按钮禁用（opacity 0.4），进度条未满 |
| 信件详情 | 加载中 | 全屏 spinner「正在取信...」|
| 信件详情 | 信件不存在 | 「信件不见了」提示，返回上页 |
| 对方主页 | 无最近书写 | 不展示「最近写道」区域 |
| 注册引导 | 标签少于3个 | 「下一步」按钮禁用，toast 提示 |
| 注册引导 | 标签超过5个 | 再次点击时 toast 提示「最多选5个标签」|
| 全局 | 网络异常 | toast「网络异常，请稍后重试」|
| 全局 | 云函数超时 | 自动重试1次，重试失败后提示 |
