#### 匹配算法实现
```js
// getMatches 云函数的核心逻辑
function calcScore(userA, userB) {
  const setA = new Set(userA.tags)
  const setB = new Set(userB.tags)
  const intersection = [...setA].filter(t => setB.has(t)).length
  const union = new Set([...setA, ...setB]).size
  let score = union === 0 ? 0 : Math.round((intersection / union) * 100)

  if (userA.active_time === userB.active_time) score += 10
  if (userA.letter_freq === userB.letter_freq)  score += 5
  if (isActiveRecently(userB.last_active))       score += 8
  return Math.min(score, 100)
}
```

### 交付物验收标准
- 所有 P0 Bug 修复完毕，P1 Bug 有计划
- 首封信发出率 ≥ 60%
- 7 日留存率 ≥ 40%
- 书信回复率 ≥ 50%
- 小程序审核通过，正式上线

### 任务清单

#### 内测准备
- [ ] 招募内测用户 50–100 名（目标用户群体：20–28 岁，有写日记习惯）
- [ ] 准备内测问卷（重点收集：匹配感、书信质量、等待感受）
- [ ] 配置内测环境与正式环境隔离
- [ ] 准备官方平常信使账号，向所有内测用户发出欢迎信

#### 测试执行
- [ ] 冒烟测试：覆盖注册 → 推荐 → 写信 → 收信 → 回信完整链路
- [ ] 回归测试：对照 TC-L01–L06、TC-A01–A05、TC-M01–M04 全部执行
- [ ] 兼容性测试：iPhone SE（小屏）/ iPhone 14（主流）/ Redmi Note 8（低端安卓）

#### 上线判断指标

| 指标 | 目标值 | 实测值 | 是否达标 |
|------|--------|--------|----------|
| 首封信发出率（注册后 3 日内）| ≥ 60% | — | — |
| 7 日留存率 | ≥ 40% | — | — |
| 书信回复率 | ≥ 50% | — | — |
| 拆信动画完整播放率 | ≥ 95% | — | — |

> 所有指标达标后，方可进入正式上线流程。若有指标未达标，优先修复后重测。

#### 审核准备
- [ ] 准备用户协议（需包含：数据收集说明、隐私政策、内容规范）
- [ ] 准备隐私政策页面（小程序内嵌页面）
- [ ] 确认小程序类目（社交类，需准备相应资质）
- [ ] 录制审核视频（展示核心功能流程，时长 ≤ 3 分钟）
- [ ] 提交小程序代码审核

#### 上线
- [ ] 灰度上线（10% 流量，观察 24 小时）
- [ ] 监控云函数错误率和响应时间
- [ ] 正式全量上线
